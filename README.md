# 2026 초과근무 계산기

Microsoft Excel용 매크로 통합문서(`.xlsm`)입니다.

## 현재 버전

**v3.2** — `2026초과v3.2.xlsm`  
배포일: 2026-10-01

공식 v3.2 SHA-256:

v3.1은 이전 버전 보존용입니다. 신규 사용은 v3.2를 권장합니다.

## v3.2 변경사항

- 휴일초근이 `예`일 때 휴일 초과시간의 일일상한이 4시간으로 고정되던 오류를 수정했습니다. 휴일도 `설정!B2`의 일일상한을 사용합니다.
- 평일 일일상한의 최종 제한도 `설정!B2` 값을 직접 사용합니다. 기존 4시간/8시간 외 설정값에서 `9999`로 우회되어 사실상 상한이 해제되던 경로를 제거했습니다.
- 휴일 급량 판정을 **인정 초과시간 1시간 1분 이상(3660초 이상)** 으로 수정했습니다.
- 월 초과근무 상한 기본값을 **67시간**으로 설정하고 `설정!B3`에서 변경할 수 있게 했습니다.
- 월 급량 상한을 `설정!B7`에 추가했습니다. 기본값은 **20개**이며 1~12월의 월 급량/상한미달/상한초과 계산이 모두 이 값을 참조합니다.
- 분기 상한을 `설정!B8`에 추가했습니다. 기본값은 **177시간**이며 3월·6월·9월·12월의 분기 요약이 이 값을 참조합니다.
- 오래된 계산 캐시 의존을 피하도록 계산 체인을 제거하고, Excel에서 열 때 자동 전체 재계산하도록 설정했습니다.
- 설정시트 내부의 과거 `휴일 일일 4시간` 안내도 실제 로직과 일치하도록 `설정한 일일상한`으로 수정했습니다.\n- 기존 VBA 프로젝트와 `재생성` 버튼 연결은 변경하지 않았습니다.

## 설정

실제 계산에 사용하는 값은 `설정` 시트의 **B열**입니다.

| 셀 | 설정 | v3.2 기본값 | 용도 |
|---|---|---:|---|
| `B1` | 기준년도 | 2026 | 월별 날짜/평일·휴일 재생성 기준 |
| `B2` | 일일상한 | 8시간 | 평일/휴일 일일 초과시간 최종 상한 |
| `B3` | 월상한 | 67시간 | 월별 초과시간 상한 비교 |
| `B4` | 시작시간 | 06:00 | 초과시간 인정 구간 시작 경계 |
| `B5` | 종료시간 | 23:00 | 초과시간 인정 구간 종료 경계 |
| `B6` | 휴일초근 | 예 | `예`: 휴일을 초과시간으로 계산 / `아니오`: 휴근 건수로 집계 |
| `B7` | 월급량상한 | 20개 | 월 급량 인정 상한 |
| `B8` | 분기상한 | 177시간 | 분기 초과시간 상한 비교 |

`설정` 시트 오른쪽의 `현업(예시)`는 참고용이며 실제 계산 설정값이 아닙니다.

## 작동 방식

### 날짜와 평일/휴일

`재생성` 버튼의 `RegenerateAllMonthB` 매크로는 기준년도(`B1`)에 맞춰 각 월 B열의 평일/휴일 값을 다시 구성합니다.

- 토요일·일요일은 자동으로 `휴일`로 지정합니다.
- 각 월 B열에는 `평일,휴일` 드롭다운이 적용됩니다.
- 선거일, 대체공휴일, 음력 기준 휴일 등은 B열에서 사용자가 수동으로 `휴일`로 보정합니다.
- 재생성 매크로는 B열의 평일/휴일 판정 및 드롭다운을 다루며 E/F/G열의 계산식을 다시 작성하지 않습니다.

### 평일 초과시간

각 월 시트의 C열(출근시간), D열(퇴근시간)을 기준으로 E열 `일일초과`를 계산합니다.

- `설정!B4:B5`의 시작·종료시간 범위 안에서 계산합니다.
- 기존 설계의 **10시간 공제 로직**은 그대로 유지합니다.
- 최종 결과는 `설정!B2`의 일일상한을 넘지 않습니다.
- 기존 설계 호환을 위해 `B2=4`일 때만 다음 보정이 유지됩니다.
  - 출근시간이 08:00 이상 09:00 미만이면 09:00으로 보정
  - 퇴근시간이 18:00 초과 19:01 미만이면 18:00으로 보정
- `B2=4`가 아닌 값에서는 위 4시간 전용 보정 없이 기존 일반 계산 경로를 사용합니다.

### 휴일 초과시간

`B6=예`이고 해당 일자가 `휴일`이면:

- C/D 출퇴근시간이 모두 입력된 경우 계산합니다.
- `B4:B5` 범위 내 인정시간을 계산합니다.
- 결과는 `B2`의 일일상한을 넘지 않습니다.
- v3.1의 휴일 4시간 고정 상한은 v3.2에서 제거했습니다.

`B6=아니오`이면 휴일의 E열 초과시간은 0이며, 출근시간이 입력된 휴일 건수를 월별 `휴근`으로 집계합니다.

### 급량

평일:

- 출근시간이 **07:59:59 이하**이면 오전급량 +1
- 퇴근시간이 **19:01:00 이상**이면 오후급량 +1

휴일:

- `B6=예`일 때 E열의 **인정 초과시간이 1:01:00 이상**이면 급량 +1
- 수식 경계값은 `3660초 이상`입니다.

월별 급량 요약:

- `월 급량` = `MIN(원시 급량 합계, 설정!B7)`
- `상한미달` = `MAX(0, 설정!B7 - 월 급량)`
- `상한초과` = `MAX(0, 원시 급량 합계 - 설정!B7)`
- 월별 마지막 요약행에는 원시 급량 합계도 별도로 표시합니다.

### 월 상한

각 월의 일일초과 합계를 `설정!B3`과 비교합니다.

- `초과시간`: 해당 월의 일일초과 합계
- `상한미달`: `MAX(0, 월상한 - 초과시간)`
- `상한초과`: `MAX(0, 초과시간 - 월상한)`

### 분기 상한

3월·6월·9월·12월에 분기 요약이 있습니다.

- 1분기: 1~3월
- 2분기: 4~6월
- 3분기: 7~9월
- 4분기: 10~12월
- 분기상한은 `설정!B8`을 참조합니다.
- 분기합계는 각 월의 `초과시간` 합계를 사용합니다.
- `분기미달`과 `분기초과`는 B8과의 차이를 음수가 되지 않도록 계산합니다.
- 기존 시트의 `*현업제외` 표기는 유지합니다. 계산기가 근무유형을 자동 판별하는 기능은 아니므로 실제 적용 여부는 사용자 구분에 따릅니다.

## 급량비 사용 기록

`급량` 시트 A열에 사용처를 입력할 수 있습니다.

- 각 월 I열 `급량사용` 드롭다운은 `급량` 시트 A열을 참조합니다.
- 각 월 J열에 사용금액을 입력하면 `급량` 시트의 `사용`과 `잔여`가 월 전체를 합산하여 계산됩니다.
- 이월금과 월별 신청금액은 `급량` 시트에서 직접 입력합니다.

## 사용 순서

1. Microsoft Excel에서 `2026초과v3.2.xlsm`을 엽니다.
2. 필요한 경우 매크로 사용을 허용합니다.
3. `설정` 시트 B1:B8을 확인하거나 변경합니다.
4. 기준년도를 변경했다면 `재생성` 버튼을 누릅니다.
5. 각 월 B열에서 자동으로 잡히지 않는 공휴일을 수동 보정합니다.
6. C열 출근시간과 D열 퇴근시간을 `hh:mm` 형식으로 입력합니다.
7. E~G열과 월/분기 요약을 확인합니다.
8. 급량비를 기록할 경우 I열에서 사용처를 선택하고 J열에 금액을 입력합니다.

## 호환성 및 주의사항

- VBA를 사용하는 `.xlsm` 파일이므로 **Microsoft Excel 데스크톱 사용을 권장**합니다.
- 웹 미리보기나 일부 비-Excel 스프레드시트 프로그램은 수식 또는 매크로를 완전히 계산하지 못할 수 있습니다.
- 출퇴근시간은 같은 날짜 안의 시간 입력을 전제로 합니다. 자정을 넘는 근무를 별도 일자로 자동 분할하는 기능은 없습니다.
- 설정값은 숫자/시간/`예·아니오` 형식을 유지해야 합니다.
- 분기 요약은 월상한으로 잘라낸 값이 아니라 각 월의 `초과시간` 합계를 비교하는 기존 설계를 유지합니다.
