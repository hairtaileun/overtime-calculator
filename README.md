# 2026 초과근무 계산기

Microsoft Excel용 매크로 통합문서(`.xlsm`)입니다.

## 현재 버전

**v3.2** — `2026초과v3.2.xlsm`  
배포/재검증일: 2026-10-01

공식 v3.2 SHA-256:

```text
e509d16a4dc832e26dd2f143f80b7ebc13dd3abd7c4b25e20df69fe05b0c3d80
```

파일 크기: **111,994 bytes**

> 2026-10-01에 처음 업로드된 v3.2 파일은 XML 재직렬화 과정에서 일부 OOXML Markup Compatibility 네임스페이스 선언이 누락되어 Microsoft Excel에서 복구 경고 또는 "파일이 손상되어 열 수 없습니다"가 발생할 수 있었습니다. 현재 `main`의 v3.2는 원본 XML 구조와 네임스페이스 선언을 보존하는 방식으로 다시 생성하고 전수 재검증한 교체본입니다.

v3.1은 이전 버전 보존용입니다. 신규 사용은 현재 v3.2를 사용하십시오.

## v3.2 변경사항

- 휴일초근이 `예`일 때 휴일 초과시간의 일일상한이 4시간으로 고정되던 오류를 수정했습니다. 휴일도 `설정!B2`의 일일상한을 사용합니다.
- 평일 일일상한의 최종 제한도 `설정!B2` 값을 직접 사용합니다. 기존 4시간/8시간 외 설정값에서 `9999`로 우회되어 사실상 상한이 해제되던 경로를 제거했습니다.
- 휴일 급량 판정을 **인정 초과시간 1시간 1분 이상(3660초 이상)** 으로 수정했습니다.
- 월 초과근무 상한 기본값을 **67시간**으로 설정하고 `설정!B3`에서 변경할 수 있게 했습니다.
- 월 급량 상한을 `설정!B7`에 추가했습니다. 기본값은 **20개**이며 1~12월의 월 급량/상한미달/상한초과 계산이 모두 이 값을 참조합니다.
- 분기 상한을 `설정!B8`에 추가했습니다. 기본값은 **177시간**이며 3월·6월·9월·12월의 분기 요약이 이 값을 직접 참조합니다.
- 설정 시트 안내에서 과거 `휴일 일일 4시간` 고정 설명을 제거하고 실제 계산과 동일하게 `설정한 일일상한`으로 수정했습니다.
- 설정 시트의 `상한시간` 명칭을 실제 의미에 맞게 `월상한`으로 정리했습니다.
- 오래된 계산 체인(`calcChain`)을 제거하고 Excel이 파일을 열 때 전체 재계산하도록 설정했습니다.
- 기존 VBA 프로젝트와 `재생성` 버튼 연결은 변경하지 않았습니다.

## 설정

실제 계산에 사용하는 값은 `설정` 시트의 **B열**입니다.

| 셀 | 설정 | v3.2 기본값 | 용도 |
|---|---|---:|---|
| `B1` | 기준년도 | 2026 | 월별 날짜/평일·휴일 재생성 기준 |
| `B2` | 일일상한 | 8시간 | 평일/휴일 일일 초과시간 최종 상한 |
| `B3` | 월상한 | 67시간 | 월별 초과시간 상한 비교 |
| `B4` | 시작시간 | 06:00 | 초과시간 인정 구간 시작 경계 |
| `B5` | 종료시간 | 23:00 | 초과시간 인정 구간 종료 경계 |
| `B6` | 휴일초근 | 예 | `예`: 휴일을 초과시간으로 계산 / `아니오`: 휴근 건수로 집계 |
| `B7` | 월급량상한 | 20개 | 월 급량 인정 상한 |
| `B8` | 분기상한 | 177시간 | 분기 초과시간 상한 비교 |

`설정` 시트 오른쪽의 `현업(예시)`와 `일반(예시)`는 참고용이며 실제 계산에 사용하는 값은 아닙니다.

## 작동 방식

### 1. 날짜와 평일/휴일

`재생성` 버튼의 `RegenerateAllMonthB` 매크로는 기준년도(`B1`)에 맞춰 각 월 B열의 평일/휴일 값을 다시 구성합니다.

- 토요일·일요일은 자동으로 `휴일`로 지정합니다.
- 각 월 B열에는 `평일,휴일` 드롭다운이 적용됩니다.
- 선거일, 대체공휴일, 음력 기준 휴일 등은 B열에서 사용자가 수동으로 `휴일`로 보정합니다.
- 재생성 매크로는 월별 B열과 해당 드롭다운을 다루며 E/F/G열 계산식을 다시 작성하지 않습니다.

### 2. 평일 초과시간

각 월 시트의 C열(출근시간), D열(퇴근시간)을 기준으로 E열 `일일초과`를 계산합니다.

- `설정!B4:B5`의 시작·종료시간 범위 안에서 계산합니다.
- 기존 설계의 **10시간 공제 로직**을 유지합니다.
- 최종 결과는 `설정!B2`의 일일상한을 넘지 않습니다.
- 기존 설계 호환을 위해 `B2=4`일 때만 다음 시간 보정이 유지됩니다.
  - 출근시간이 08:00 이상 09:00 미만이면 09:00으로 보정
  - 퇴근시간이 18:00 초과 19:01 미만이면 18:00으로 보정
- `B2=4`가 아닌 값에서는 위 4시간 전용 시간보정 없이 기존 일반 계산 경로를 사용하되, 최종 일일상한은 입력한 `B2` 값을 그대로 사용합니다.

### 3. 휴일 초과시간

`B6=예`이고 해당 일자가 `휴일`이면:

- C/D 출퇴근시간이 모두 입력된 경우 계산합니다.
- `B4:B5` 범위 내 인정시간을 계산합니다.
- 결과는 `B2`의 일일상한을 넘지 않습니다.
- v3.1의 휴일 4시간 고정 상한은 제거되었습니다.

`B6=아니오`이면 휴일의 E열 초과시간은 0이며, 출근시간이 입력된 휴일 건수를 월별 `휴근`으로 집계합니다.

### 4. 급량

평일:

- 출근시간이 **07:59:59 이하**이면 오전급량 +1
- 퇴근시간이 **19:01:00 이상**이면 오후급량 +1

휴일:

- `B6=예`일 때 E열의 **인정 초과시간이 1:01:00 이상**이면 급량 +1
- 수식 경계값은 `3660초 이상`입니다.

월별 급량 요약:

- `월 급량` = `MIN(원시 급량 합계, 설정!B7)`
- `상한미달` = `MAX(0, 설정!B7 - 월 급량)`
- `상한초과` = `MAX(0, 원시 급량 합계 - 설정!B7)`
- 월별 마지막 요약행에는 원시 급량 합계도 별도로 표시합니다.

각 월 I열 `급량사용` 드롭다운은 `급량!A:A`를 참조합니다.

### 5. 월 상한

각 월의 일일초과 합계를 `설정!B3`과 비교합니다.

- `초과시간`: 해당 월의 일일초과 합계
- `상한미달`: 월상한에서 초과시간을 뺀 값(최소 0)
- `상한초과`: 초과시간에서 월상한을 뺀 값(최소 0)

월 총합 자체를 67시간으로 잘라 저장하는 방식이 아니라, 기존 설계대로 실제 계산된 월 초과시간과 월상한을 비교해 미달/초과를 별도로 표시합니다.

### 6. 분기 상한

3월·6월·9월·12월에 분기 요약이 있습니다.

- 1분기: 1~3월
- 2분기: 4~6월
- 3분기: 7~9월
- 4분기: 10~12월
- `L1`, `L6`, `L7`은 모두 `설정!B8`의 분기상한을 직접 참조합니다.
- 분기합계는 각 월의 `초과시간` 합계를 사용합니다.
- `분기미달`과 `분기초과`는 설정한 분기상한과의 차이를 음수가 되지 않도록 계산합니다.
- 기존 시트의 `*현업제외` 표기는 유지합니다. 계산기가 근무유형을 자동 판별하는 기능은 아니므로 실제 적용 여부는 사용자 구분에 따릅니다.

## 급량비 사용 기록

`급량` 시트 A열에 사용처를 입력할 수 있습니다.

- 각 월 I열 `급량사용` 드롭다운은 `급량!A:A`를 참조합니다.
- 각 월 J열에 사용금액을 입력하면 `급량` 시트의 `사용`과 `잔여`가 월 전체를 합산하여 계산됩니다.
- 이월금과 월별 신청금액은 `급량` 시트에서 직접 입력합니다.

## 사용 순서

1. Microsoft Excel에서 `2026초과v3.2.xlsm`을 엽니다.
2. 필요한 경우 매크로 사용을 허용합니다.
3. `설정` 시트 B1:B8을 확인하거나 변경합니다.
4. 기준년도를 변경했다면 `재생성` 버튼을 누릅니다.
5. 각 월 B열에서 자동으로 잡히지 않는 공휴일을 수동 보정합니다.
6. C열 출근시간과 D열 퇴근시간을 `hh:mm` 형식으로 입력합니다.
7. E~G열과 월/분기 요약을 확인합니다.
8. 급량비를 기록할 경우 I열에서 사용처를 선택하고 J열에 금액을 입력합니다.

## GitHub/웹에서 받은 파일의 매크로 차단 해제

GitHub 또는 웹 브라우저에서 `.xlsm` 파일을 내려받으면 Windows가 파일에 **Mark of the Web(MOTW, Zone.Identifier)** 를 붙일 수 있습니다. 이 경우 Excel 상단에 다음과 같은 붉은 보안 경고가 표시될 수 있습니다.

> 보안 위험 — Microsoft는 이 파일의 출처를 신뢰할 수 없기 때문에 매크로 실행을 차단했습니다.

이 경고는 **통합문서가 손상되었다는 뜻이 아닙니다.** 수식 계산은 가능하지만 VBA가 차단되므로 `재생성` 버튼의 `RegenerateAllMonthB` 매크로는 실행되지 않습니다.

현재 GitHub `main`의 공식 v3.2 파일을 사용한다면 먼저 README 상단의 SHA-256과 다운로드한 파일의 해시가 일치하는지 확인한 뒤, 파일을 신뢰하는 경우에만 다음 방법으로 차단을 해제하십시오.

### 파일 탐색기에서 해제

1. Excel을 완전히 종료합니다.
2. 파일 탐색기에서 `2026초과v3.2.xlsm`을 마우스 오른쪽 버튼으로 클릭합니다.
3. **속성 → 일반** 탭으로 이동합니다.
4. 창 아래쪽에 **차단 해제**가 표시되면 체크합니다.
5. **적용 → 확인**을 누릅니다.
6. 파일을 다시 열어 `재생성` 버튼을 사용합니다.

### PowerShell에서 해제

파일 속성에 `차단 해제`가 보이지 않거나 명령으로 처리하려면 Excel을 닫은 뒤 다음과 같이 실행할 수 있습니다.

```powershell
Unblock-File -LiteralPath "C:\파일경로\2026초과v3.2.xlsm"
```

경로는 실제 다운로드 위치로 바꾸어야 합니다.

> **주의:** 출처를 확인하지 않은 `.xlsm` 파일의 차단을 임의로 해제하지 마십시오. 이 저장소의 공식 배포본인지 확인하고 SHA-256이 README에 기재된 값과 일치하는 경우에만 해제하는 것을 권장합니다.

## 전수 감사 러너

저장소에는 Windows/Excel 실기 검증용 감사 러너가 포함됩니다.

- `RUN-AUDIT.cmd`: 원클릭 실행기
- `tools/audit-v32.ps1`: 실제 감사 로직
- 기본 대상: 저장소 루트의 `2026초과v3.2.xlsm`

실행:

```text
RUN-AUDIT.cmd
```

PowerShell에서 직접 실행하려면:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\audit-v32.ps1
```

감사 러너는 원본 파일을 직접 수정하지 않고 임시 복사본으로 Excel 런타임 검사를 수행합니다. 주요 검사항목은 다음과 같습니다.

- ZIP/OOXML 엔트리, XML/RELS/VML strict parsing
- `mc:Ignorable` / `mc:Choice Requires` namespace 완전성
- 내부 relationship target과 Content Types
- 공식 v3.2 파일 SHA-256 및 VBA 프로젝트 SHA-256
- 14개 시트와 전체 재계산 설정
- `RegenerateAllMonthB` 버튼의 매크로 연결
- 1~12월 전체 수식 패턴 및 과거 오류 수식 잔존 여부
- Microsoft Excel COM으로 정상 열기
- `CalculateFullRebuild` 후 수식 오류 셀 검사
- 휴일 일일상한 8시간 및 임의값 6시간 시나리오
- 휴일 급량 1:00 → 0 / 1:01 → 1 경계값
- 월상한 66/67/68시간
- 월급량상한 19/20/21
- 분기상한 176/177/178시간
- `RegenerateAllMonthB` 매크로 실제 실행 및 2027년 주말 판정
- Excel 저장 → 닫기 → 재오픈 round-trip

필수 검사항목 중 하나라도 실패하면 exit code `90`으로 종료합니다. 성공하면 `0`입니다. 결과는 기본적으로 저장소 루트의 다음 파일에 기록됩니다.

- `audit-evidence.json`
- `audit-evidence.txt`

GitHub에 커밋할 필요가 없는 실행 증적이므로 이 두 파일은 로컬 검증용으로 취급합니다.

### AHO Work-PC 실행 경계

이 러너는 Microsoft Excel이 설치된 Windows 환경에서 실행해야 하며 AHO Work-PC self-hosted runner에서의 실기 검증을 목표로 합니다. AHO의 현재 GitHub command ingress가 활성화되지 않은 상태에서는 이를 H4 broker-enforced 실행으로 표현하지 않습니다. AHO 쪽 실행 권한/lease가 허용되는 generation에서 self-hosted Work-PC 실행으로 검증해야 합니다.

## 호환성 및 주의사항

- VBA를 사용하는 `.xlsm` 파일이므로 **Microsoft Excel 데스크톱 사용을 권장**합니다.
- 웹 미리보기나 일부 비-Excel 스프레드시트 프로그램은 수식 또는 매크로를 완전히 계산하지 못할 수 있습니다.
- 출퇴근시간은 같은 날짜 안의 시간 입력을 전제로 합니다. 자정을 넘는 근무를 별도 일자로 자동 분할하는 기능은 없습니다.
- 설정값은 숫자/시간/`예·아니오` 형식을 유지해야 합니다.
- 분기 요약은 월상한으로 잘라낸 값이 아니라 각 월의 `초과시간` 합계를 비교하는 기존 설계를 유지합니다.

## v3.2 전수 재검증

현재 배포본은 기존 정상 통합문서를 기준으로 **수정 대상 셀/수식만 패치**하고, 그 외 OOXML을 재직렬화하지 않는 방식으로 다시 생성했습니다. 이를 통해 초기 v3.2에서 발생했던 네임스페이스 선언 손상을 제거했습니다.

검증 항목:

- ZIP CRC 및 중복 엔트리 검사 통과
- 모든 XML/RELS/VML 파트를 strict XML 파서로 재검증
- 모든 `mc:Ignorable`, `mc:Choice Requires` prefix의 실제 namespace 선언 존재 확인
- 모든 내부 relationship target 존재 및 `r:id` 연결 확인
